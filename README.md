# 🍕 WebNest Pizza

Site demonstrativo de uma pizzaria contemporânea desenvolvido como parte do portfólio da **WebNest**.

O projeto foi criado com foco em um design moderno, minimalista e responsivo, apresentando a identidade visual da pizzaria, seu cardápio e sua história, com pedidos realizados diretamente pelo WhatsApp.

Versão 1.0

## 🌐 Demonstração

🔗 **Acesse o site:** [WebNest Pizza](https://gabriel-silira.github.io/WebNest-Pizza/)

> O projeto está hospedado pelo GitHub Pages.

---

## 📸 Sobre o projeto

O **WebNest Pizza** é um projeto fictício desenvolvido para demonstrar as possibilidades de criação de sites profissionais para empresas do ramo alimentício.

A proposta foi criar uma experiência visual elegante e contemporânea, utilizando uma combinação de tons escuros, creme, vermelho e laranja, valorizando as imagens e a apresentação dos conteúdos.

O site conta com:

- 🏠 Página inicial com seção Hero
- 🍕 Página de cardápio
- 📖 Página Nossa História
- 💬 Botões para pedidos via WhatsApp
- 📱 Design responsivo
- 🎨 Identidade visual própria
- ✨ Animações e interações na interface
- 🔎 Arquivos `robots.txt` e `sitemap.xml`
- ⚡ Layout adaptável a diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura e organização das páginas
- **CSS3** — estilização, layouts e efeitos visuais
- **CSS Media Queries** — responsividade para diferentes dispositivos
- **JavaScript** — interações e funcionalidades do site
- **Google Fonts** — tipografia
- **GitHub Pages** — hospedagem do site

### Fontes utilizadas

O projeto utiliza principalmente:

- **Oswald** — títulos e elementos de destaque
- **Inter** — textos e elementos da interface

## 🎨 Identidade visual

A identidade visual da WebNest Pizza foi construída com uma paleta inspirada em pizzarias contemporâneas, combinando tons escuros e cores quentes.

| Cor             | Hexadecimal | Utilização                            |
| --------------- | ----------- | ------------------------------------- |
| Preto carvão    | `#101010`   | Fundos principais e elementos escuros |
| Creme artesanal | `#F5EBDD`   | Textos e elementos claros             |
| Vermelho tomate | `#D62828`   | Botões e destaques                    |
| Laranja forno   | `#F4A261`   | Detalhes e elementos de interação     |
| Marrom espresso | `#292521`   | Fundos secundários e superfícies      |

A proposta visual prioriza a simplicidade, o contraste, a tipografia e a utilização estratégica das imagens, mantendo uma identidade consistente entre as páginas.

---

## 🍕 Cardápio e pedidos

O site possui uma página dedicada ao cardápio, permitindo que os visitantes conheçam as opções disponíveis e acessem os canais de pedido.

Os principais recursos dessa experiência são:

- Apresentação visual dos produtos.
- Organização do conteúdo para facilitar a navegação.
- Acesso ao WhatsApp por meio dos botões de pedido.
- Mensagens de contato preparadas para facilitar o início da conversa.

O projeto não utiliza checkout ou pagamento online. Os pedidos são direcionados ao WhatsApp.

---

## 📖 Nossa História

A página **Nossa História** apresenta a identidade da WebNest Pizza e o conceito por trás da marca.

O conteúdo é organizado em uma composição visual que combina textos, imagens e elementos tipográficos, mantendo o mesmo padrão de design da página inicial e do cardápio.

---

## 📱 Responsividade e experiência do usuário

O site foi estruturado para se adaptar a diferentes tamanhos de tela, mantendo uma experiência consistente em computadores, tablets e celulares.

Entre os aspectos considerados estão:

- Layouts adaptáveis.
- Navegação entre páginas.
- Organização dos elementos em telas menores.
- Botões e links com estados de interação.
- Espaçamento e legibilidade.
- Animações discretas para complementar a experiência visual.

---

## 🔎 SEO técnico

O projeto inclui arquivos básicos para auxiliar na organização e na descoberta das páginas pelos mecanismos de busca:

- **`robots.txt`** — define orientações de rastreamento para robôs compatíveis.
- **`sitemap.xml`** — lista as URLs incluídas no mapa do site.

Esses arquivos fazem parte da implementação de SEO técnico, mas sua presença, isoladamente, não garante indexação ou posicionamento nos resultados de busca.

### Organização dos arquivos

- **`index.html`** — página inicial.
- **`cardapio.html`** — página do cardápio.
- **`sobre.html`** — página Nossa História.
- **`css/style.css`** — estilos principais do site.
- **`css/responsive.css`** — regras de responsividade.
- **`js/data.js`** — arquivo destinado aos dados utilizados pelo projeto.
- **`js/script.js`** — funcionalidades e interações em JavaScript.
- **`assets/images/`** — imagens utilizadas no site.
- **`assets/icons/`** — ícones do projeto.
- **`robots.txt`** — orientações para robôs de rastreamento.
- **`sitemap.xml`** — mapa de URLs do site.

## 🚀 Objetivo do projeto

A WebNest Pizza faz parte do portfólio da **WebNest**, com o objetivo de demonstrar conhecimentos em desenvolvimento front-end, criação de interfaces responsivas, organização de código e construção de experiências digitais para negócios do setor alimentício.

O projeto também serve como demonstração de como um site pode apresentar uma marca, divulgar seus produtos e facilitar o contato com clientes por meio de uma interface moderna e funcional.
